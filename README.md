# AISELAMONBOT

بوت تيليجرام يرد باللهجة السعودية، مع نظام مراسلة مباشر بين المستخدم وصاحب البوت.

## المزايا

- زر **إرسال رسالة لصاحب البوت** في قائمة `/start`.
- تصل رسائل المستخدمين إلى صاحب البوت مع رقم تلقائي مثل `شخص 1` و`شخص 2`.
- يرد صاحب البوت على الرسالة المعروضة في محادثته، ويصل الرد تلقائيًا للمستخدم.
- `/rename <رقم الشخص أو ID> <الاسم الجديد>` لتغيير اسم أي متلقٍ، مثل `/rename 1 أحمد`.
- `/people` لعرض الأسماء وأرقام الـ IDs المسجلة.
- حفظ الأسماء ومسارات الرسائل في `bot_users.json` حتى لا تضيع بعد إعادة التشغيل.

## التشغيل

1. ثبّت الاعتمادات:

```bash
pip install -r requirements.txt
```

2. أضف الأسرار إلى بيئة التشغيل، ولا تضعها داخل الملفات أو GitHub:

```bash
export AISELAMONBOT_TOKEN="توكن البوت"
export OPENAI_API_KEY="مفتاح OpenAI"
export BOT_ADMIN_ID="8561249287"
```

`AISELAMONBOT_TOKEN` مطلوب. أما `OPENAI_API_KEY` فهو اختياري؛ بدونه يعمل البوت بردود محلية بسيطة. `BOT_ADMIN_ID` اختياري وقيمته الافتراضية هي `8561249287`.

3. شغّل البوت:

```bash
python bot.py
```

في GitHub Actions أو أي منصة استضافة، أضف الأسرار باسم `AISELAMONBOT_TOKEN` و`BOT_ADMIN_ID`، وأضف `OPENAI_API_KEY` إذا كنت تريد ردود الذكاء الاصطناعي.
